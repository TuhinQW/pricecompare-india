# PriceCompare India — Professional V1

A static, professional-looking prototype for an Amazon vs Flipkart price comparison brand.

## Included
- Responsive premium homepage
- Search/filter demo
- Product comparison cards
- Category navigation
- Buying guides
- About, affiliate disclosure and privacy pages
- Affiliate-friendly `nofollow sponsored` links
- No framework required for this prototype

## Live production stack
Recommended next phase:
- Next.js + TypeScript
- Supabase/Postgres
- Vercel
- Amazon approved API / Creators API
- Flipkart Affiliate API
- Scheduled price sync
- Product detail pages with structured SEO metadata
- Click/conversion analytics

Vercel is designed for Next.js deployment. Supabase has an official Next.js quickstart and recommends environment variables for project credentials.

## IMPORTANT
All marketplace prices, ratings, review counts and URLs in this prototype are illustrative. Do not publish them as live facts. Replace them with approved API/feed data before public launch.
